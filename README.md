# Muse Plugins

One hub page for Muse's browser extensions — small, local-first tools, free on
Microsoft Edge, with a one-time Pro purchase where offered.

Live: https://alapha888.github.io/muse-plugins/

## The four extensions

| Extension | Edge status | Pro |
|---|---|---|
| **ConvoExport** — export a ChatGPT / Claude conversation to Markdown, DOCX, or print | Live · v1.0.3 | ¥19.9 one-time (unlimited exports; free 3/day) |
| **YT Transcript Export** — export a YouTube video's subtitles to TXT / MD / SRT / VTT | Live · v0.1.0 | ¥19.9 one-time |
| **SessionSnap** — save and restore browser sessions across Chrome / Edge / Firefox | In review · v0.1.0 | coming after launch |
| **FocusBlock** — local-first website blocker (domain / keyword rules, schedules, focus timer) | Live · v0.1.0 | ¥19.9 one-time (unlimited rules; free 20 rules) |

Store links, Pro purchase links (Afdian), and privacy-policy links are on the
page itself. Each extension's source lives in its own private repository;
only this hub page and the per-extension privacy pages are public.

## Notes

- All four extensions are local-first: no accounts, no tracking, no uploads.
- This page is a static single file (`index.html`), hosted on GitHub Pages.
- No email address is listed on the page. Questions about a specific
  extension: see its privacy page.
