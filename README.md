# Muse Plugins

One hub page for Muse's browser extensions — small, local-first tools, free on
Microsoft Edge, with paid Pro upgrades where offered.

Live: https://alapha888.github.io/muse-plugins/

## The six extensions

| Extension | Edge status | Pro |
|---|---|---|
| **ConvoExport** — export a ChatGPT / Claude conversation to Markdown, DOCX, or print | Live · v1.0.4 | ¥19.9 one-time (unlimited exports; free 3/day) |
| **YT Transcript Export** — export a YouTube video's subtitles to TXT / MD / SRT / VTT | Live · v0.1.3 (v0.1.7 update in review) | ¥19.9 one-time |
| **SessionSnap** — save and restore browser sessions across Chrome / Edge / Firefox | Live · v0.1.5 (v0.1.6 update in review) | ¥19.9 one-time (365-day retention + daily backup; free 14-day retention) |
| **FocusBlock** — local-first website blocker (domain / keyword rules, schedules, focus timer) | Live · v0.1.1 (v0.1.4 update in review) | ¥19.9 one-time (unlimited rules; free 20 rules) |
| **Highlighter** — highlight text on any web page, highlights stay in the browser | Live · v0.4.2 | ¥19.90 one-time on Afdian |
| **MD Publisher** — write Markdown once, paste it formatted into WeChat / Zhihu / Juejin | Live · v2.1.4 · 7 users (Nov 26) | ¥19.9 one-time |

Store links, Pro purchase links (Afdian), and privacy-policy links are on the
page itself. Each extension's source lives in its own private repository;
only this hub page and the per-extension privacy pages are public.

## Notes

- All six extensions are local-first: no accounts, no tracking, no uploads.
- This page is a static single file (`index.html`), hosted on GitHub Pages.
- No email address is listed on the page. Questions about a specific
  extension: see its privacy page.
